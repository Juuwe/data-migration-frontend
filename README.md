# data-migration-frontend

Фронтенд сервиса методов миграции данных на React + TypeScript. Бэкенд: [data-migration-backend](https://github.com/Juuwe/data-migration-backend).

## Стек

- React, TypeScript, Vite;
- React Router;
- React-Bootstrap, Bootstrap Icons.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на <http://localhost:3000>.

Сборка: `npm run build`, проверка линтером: `npm run lint`.

## Страницы

Интерфейс сверстан под вертикальный экран телефона. Внизу всех страниц — панель навигации из четырех пунктов: «Лента», «Добавить», «Плитка», «Вход». Для гостя доступны только «Лента» и «Плитка».

Данные карточек пока берутся из mock-коллекции `src/modules/mock.ts`. Функции в `src/modules/methodsApi.ts` повторяют поведение `GET /api/methods` и `GET /api/methods/feed`.

### Лента — `/feed`, `/feed/:id`

Одна услуга миграции на весь экран. Без id открывается первая услуга, с id — выбранная в плитке.

- видео услуги проигрывается автоматически на фоне;
- снизу название и краткое описание с кнопкой «больше / меньше»;
- справа количество лайков, кнопка «Дальше» (следующая услуга, после последней — первая) и два поля по теме: время на 1 Гб (сек/Гб) и коэффициент надежности.

### Плитка — `/methods`

Список опубликованных услуг в два столбца.

- фильтр по времени на 1 Гб: слайдер с двумя ползунками (от 0.01 до 1 сек/Гб) и кнопка «Найти». Примененный фильтр сохраняется в адресе как `?min_time=&max_time=`;
- в карточке изображение, название, количество лайков и время на 1 Гб;
- по клику на карточку открывается лента с этой услуги.

Если у услуги нет изображения или видео либо файл недоступен, показываются `public/images/default.svg` и `public/videos/default.mp4`.
