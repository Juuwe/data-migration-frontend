# data-migration-frontend

Фронтенд сервиса методов миграции данных на React + TypeScript. Бэкенд: [data-migration-backend](https://github.com/Juuwe/data-migration-backend).

## Стек

- React, TypeScript, Vite;
- React Router;
- React-Bootstrap, Bootstrap Icons.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на <http://localhost:3000>.

Сборка: `npm run build`, проверка линтером: `npm run lint`.

## Страницы

Интерфейс повторяет страницы ленты и плитки из SSR-версии бэкенда. Внизу всех страниц панель навигации: «Лента», «Добавить», «Плитка», «Вход». Для гостя доступны только «Лента» и «Плитка».

Данные карточек берутся из mock-коллекции `src/modules/mock.ts`, изображения и видео загружаются из MinIO. Функции в `src/modules/methodsApi.ts` повторяют `GET /api/methods` и `GET /api/methods/feed`.

### Лента — `/feed?id={id}&next=true`

Без параметров открывается первая опубликованная услуга, с `id` — услуга по ID, с `id` и `next=true` — следующая после нее.

- видео услуги на фоне с автопроигрыванием;
- снизу название и краткое описание с кнопкой «больше»;
- справа количество лайков, кнопка «Дальше» и два поля по теме: время на 1 Гб и коэффициент надежности.

### Плитка — `/grid?min_time={min}&max_time={max}`

Список опубликованных услуг в два столбца.

- фильтр по времени на 1 Гб: слайдер с двумя ползунками и кнопка «Найти», значения фильтра сохраняются после поиска;
- в карточке изображение, название, количество лайков и время на 1 Гб;
- по клику на карточку открывается лента с этой услуги.

Если у услуги пустое поле изображения или видео, показываются `public/images/default.svg` и `public/videos/default.mp4`.
