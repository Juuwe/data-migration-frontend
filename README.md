# data-migration-frontend

Фронтенд сервиса методов миграции данных на React + TypeScript. Бэкенд: [data-migration-backend](https://github.com/Juuwe/data-migration-backend).

## Стек

- React, TypeScript, Vite;
- React Router;
- React-Bootstrap, Bootstrap Icons;
- Redux Toolkit, React Redux;
- axios, swagger-typescript-api.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (Vite 8).

```bash
npm install
npm run dev
```

Приложение откроется на <http://localhost:3000>. Сборка: `npm run build`, проверка линтером: `npm run lint`.

Для работы с бэкендом поднимите инфраструктуру из репозитория `data-migration-backend`:

```bash
docker compose up -d
```

Веб-сервис будет доступен на `http://localhost:8081`, MinIO — на `http://localhost:9010`. Тестовые пользователи из `migrations/init.sql`: `student@example.com`, `analyst@example.com`, `engineer@example.com`, `architect@example.com`, `reviewer@example.com`, пароль `password123`.

### Проксирование

В `vite.config.ts` настроены два маршрута, которые решают проблему CORS:

- `/api` → `http://localhost:8081` — запросы к веб-сервису;
- `/s3` → `http://localhost:9010` — объекты MinIO, префикс `/s3` отбрасывается.

Ссылки на MinIO, которые возвращает API, приводятся к виду `/s3/{bucket}/{key}` в `src/modules/media.ts`.

## Кодогенерация API

```bash
npm run generate-api
```

Скрипт `scripts/generate-api.mjs` берёт OpenAPI-схему из `http://localhost:8081/docs/swagger.yaml` и создаёт `src/api/Api.ts` с axios-клиентом. Другой адрес можно передать через переменную окружения:

```bash
API_SWAGGER_URL=http://localhost:8081/docs/swagger.yaml npm run generate-api
```

Экземпляр сгенерированного клиента находится в `src/api/index.ts`; он автоматически добавляет `Authorization: Bearer <JWT>` к запросам.

## Redux Toolkit

Хранилище описано в `src/store.ts`, слайсы — в `src/slices`:

- `methodsSlice` — фильтр по времени, список услуг, лента, лайки и удаление; запросы к домену услуг выполняются через `createAsyncThunk` и сгенерированный axios-клиент;
- `draftSlice` — черновик пользователя, создание и публикация услуги;
- `userSlice` — email, признак авторизации, загрузка и ошибки.

Redux DevTools подключается автоматически в режиме разработки. При выходе из аккаунта фильтр услуг сбрасывается к значениям по умолчанию.

Запросы авторизации и деавторизации выполняются напрямую через axios (`src/modules/authApi.ts`), без кодогенерации и thunk. JWT сохраняется в `localStorage` и cookie, поэтому после перезагрузки страницы Redux снова находится в состоянии гостя, а токен остаётся в браузере.

Во время любого запроса поверх интерфейса показывается `LoadingOverlay`, который блокирует кнопки и поля.

## Страницы

Навигация снизу: «Лента», «Добавить», «Плитка», «Вход». После авторизации пункт «Вход» заменяется кнопкой «Выход».

### Лента — `/feed?id={id}&next=true`

Одна опубликованная услуга с видео на фоне. Без параметров открывается первая услуга, с `id` — услуга по ID, с `id` и `next=true` — следующая. Снизу название и краткое описание с кнопкой «больше / меньше», справа количество лайков, кнопка «Дальше» и два поля по теме. Авторизованный пользователь может поставить или снять лайк; гостя кнопка ведёт на страницу входа.

### Плитка — `/grid?min_time={min}&max_time={max}`

Список опубликованных услуг в два столбца. Фильтр по времени на 1 Гб хранится в Redux и передаётся в запрос `GET /api/methods`; после поиска значения сохраняются в адресной строке. В карточке изображение, название, количество лайков и время на 1 Гб. Авторизованному создателю показывается кнопка удаления собственной услуги. По клику на карточку открывается лента с этой услуги.

### Добавление — `/add`

Доступна только авторизованному пользователю, гостя перенаправляет на `/login`. Если у пользователя есть черновик, страница показывает его медиа и форму публикации: описание, время на 1 Гб, коэффициент надёжности. Если черновика нет — форму создания: название, изображение и видео. После публикации происходит переход в ленту на новую услугу.

### Вход — `/login`

Форма входа. Запрос идёт напрямую через axios. После успешного входа состояние пользователя записывается в Redux, в меню появляется «Выход».

Диаграмма прецедентов интерфейса React находится в `docs/use-case-react.puml`.

## Mock-данные

Если бэкенд недоступен и пользователь находится в состоянии гостя, список услуг и лента берутся из mock-коллекции `src/modules/mock.ts`. Авторизация и изменяющие запросы без бэкенда не работают.

Если у услуги пустое поле изображения или видео, показываются `public/images/default.svg` и `public/videos/default.mp4`. Медиафайлы MinIO загружаются через прокси `/s3`.
